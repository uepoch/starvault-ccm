StarVault CCM

Install, switch, and launch StarCraft II custom campaigns.

StarVault CCM manages your custom campaigns the way you already think about them: four campaign slots, one click each. Import any community package zip — any layout — and switch campaigns without touching a file explorer.

Why it's safe

  • No overwrites, ever. Two packages shipping different content for the same dependency are caught before anything changes on disk.
  • Every import is confirmed. Detected title, author, and slot guess are shown for you to check — nothing is silently guessed into the wrong campaign.
  • Switches are transactions. Stage, verify, swap, roll back on failure. A crash mid-switch repairs itself at next startup.
  • Your old installs migrate. Existing CCM campaigns are imported through the same checked pipeline; originals stay untouched.
