StarVault CCM

The unworthy successor of 7Ace's CCM.

Download for Windows (Alpha) macOS coming soon

Pre-Alpha releases. If a campaign package fails to import, please report it or ping me on Discord with the operation log.

Features

  • Import anything the community ships. Zip or drag-and-drop, packed or unpacked, nested layouts included; most packages the old CCMv1 format could not handle just work.
  • Opt-in save isolation Beta. Enabling it first backs up the selected profile. Save and profile settings stay locked while a custom campaign is active.
  • Quick-play. Play checks the current state, activates the chosen campaign only when needed, and launches it.
  • Journaled switches. StarVault stages and verifies the whole target, records each swap phase, and keeps backups until the ledger commit verifies.
  • No dependency soup. Shared .SC2Mod files are deduplicated. A different unowned file at a target path blocks activation before a swap.
  • Migrates your old setup. Existing CCM campaigns import through the same checked pipeline; originals stay untouched.
  • Signed updates. Official releases publish a signed updater manifest only after tests and dependency audits pass.
