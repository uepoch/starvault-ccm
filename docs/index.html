StarVault CCM

A successor to 7Ace's CCM.

Keep one custom campaign active, switch back to vanilla when you are done, and launch through Battle.net from the same Library screen.

Download for Windows 10+ (Alpha)

This is alpha software. If a campaign fails to import or recover, report it or ping me on Discord with the operation log. Review the log before sharing it because it contains local file paths.

What it does

  • One active campaign. Library shows exactly what is active and provides a clear Return to vanilla action.
  • Flexible imports. Import zip archives with packed or unpacked maps and Mods. The importer handles common wrapper folders and nested game layouts, and shows the detected faction before it writes the package.
  • Separate Activate and Play actions. Activate prepares the campaign without launching the game. Play activates only when needed, then starts StarCraft II.
  • Recoverable switching. StarVault records each swap phase and keeps its backups until the new state commits. If the app stops midway, startup recovery finishes or rolls back the operation.
  • External Mods stay visible. Matching files are left in place. If a campaign needs different bytes at the same path, StarVault asks before replacing them and explains that the replacement becomes permanent after activation commits.
  • Optional save isolation Beta. Enabling it first backs up the selected profile. Save and profile settings stay locked while a custom campaign is active.
  • Import from SC2CCM. StarVault can copy campaigns from an existing SC2CCM setup without changing the originals.
  • Signed updates. Official releases publish a signed updater manifest only after tests and dependency audits pass.
