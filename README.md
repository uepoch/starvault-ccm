# StarVault CCM

**Install, switch, and launch StarCraft II custom campaigns.**

StarVault CCM is a modern successor to the SC2 Custom Campaign Manager (SC2CCM).
It manages a local library of custom campaign packages, deploys them into the
game's fixed campaign slots, resolves `.SC2Mod` dependencies through a
content-addressed store, and launches the game with the right campaigns active.

Status: **pre-alpha, design phase**. See [`docs/`](docs/) for the decision
record, the architectural review of the original tool, and the design documents.

## Naming policy

The official releases of StarVault CCM are the ones published from this
repository and distributed via `ccm.starvault.dev`. Modified or renamed builds
must state clearly that they are unofficial. This project is not affiliated
with or endorsed by Blizzard Entertainment; "StarCraft II" is used
descriptively only.
